# Neuromorphic Research Project

This is a research project, run under a three-layer setup:

1. **Research constitution** (permanent, rarely changes): @research/RESEARCH_OS.md
2. **Project brief** (evolves with evidence; keep it current): @research/PROJECT_BRIEF.md
3. **Experiment ledger** (append a row per experiment): `research/EXPERIMENT_LEDGER.md`

Follow the constitution in every session. When evidence changes the project (title, hypothesis, closest work, weaknesses, stage), update `PROJECT_BRIEF.md` in the same turn.
